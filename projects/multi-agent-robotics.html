Project overview

The system work brings perception, memory and decision-making into a modular multi-agent structure. These components connect observations and task context with decisions, while robot-control logic links those decisions to physical actions.

My internship work covered both agent development and robotic software integration. Using Python and ROS2, I implemented control logic for path planning and obstacle avoidance, and tested the integrated components to support autonomous task execution and interaction.

Key work

  • Developed modular LLM-based multi-agent systems integrating perception, memory and decision-making modules.
  • Implemented Python and ROS2 control logic supporting path planning, obstacle avoidance and system integration.
  • Tested and optimised AI agents and robotic systems for autonomous task execution and interaction.
