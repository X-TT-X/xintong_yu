Brain Tumor Identification and Prediction System Based on VGG19 and SVM

2025.02 – 2025.06

Project Code↗All projects ↗

Project overview

This project connects image analysis and machine-learning prediction with a web interface. The MRI classification component uses VGG19, while the prediction component uses SVM, bringing the two workflows into one identification and prediction system.

My work involved applying convolutional neural network methods to MRI images, using machine-learning methods for prediction, and developing the web-based system. The project received the Outstanding Bachelor’s Thesis award at Shandong Agricultural University.

Key work

  • Applied convolutional neural network methods to MRI-based brain tumour identification and classification.
  • Used machine-learning methods for prediction.
  • Developed a web-based identification and prediction system.

Awarded Outstanding Bachelor’s Thesis at Shandong Agricultural University.
