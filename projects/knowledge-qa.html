Intelligent Q&A System Based on Agricultural Knowledge Mapping

2023.07 – 2023.11

Project Code↗All projects ↗

Project overview

The project combines an agricultural knowledge-mapping Q&A interface with the supporting back-end and database interaction. Its scope includes how agricultural information is presented, how users interact with the interface, and how the application components communicate.

My contributions covered page and interface design using Adobe XD and Sketch, front-end development, integration between the front end, back end and database, and system testing. The project received First Prize in the Shandong College Student Software Design Competition in 2023.

Key work

  • Used Adobe XD and Sketch for page design and front-end interface development.
  • Implemented interaction between the front end, back end and database.
  • Tested the system to verify its performance and accuracy.

First Prize, Shandong College Student Software Design Competition, 2023.
