Project overview

This mobile shopping application was developed using Uni-app and Vue. The project includes product browsing, grouped category navigation and account interfaces, giving users a way to explore a catalogue and access login and registration views.

The supplied product-list source includes a keyword-search component, sorting tabs, product images, prices and scroll-based loading. The category page groups product imagery into browsable sections. The animation shown here uses these original project assets to preview the shopping interface.

Key work

  • Product-list interface with keyword search, sorting tabs and scroll-based loading.
  • Category navigation with product imagery and grouped categories.
  • Account interfaces for login and registration.
