PROJECT DETAIL

Research on Optimal Aircraft Trajectory Based on the Combination of A* Search Algorithm and Monte Carlo Method

2022.12 – 2024.07

Project Code↗All projects ↗

Project overview

This research considers aircraft trajectory planning from both a search-algorithm and a simulation perspective. Monte Carlo analysis was used to examine the planning problem, while A* search provided the focus for studying possible trajectory-planning paths.

My work included analysing the problem using the Monte Carlo method, studying and improving A* search, and assessing the feasibility of the approach. MATLAB simulations were used to represent and examine the resulting aircraft paths.

Key work

  • Used the Monte Carlo method to analyse aircraft trajectory planning.
  • Studied and improved the A* search algorithm and analysed its feasibility.
  • Simulated aircraft trajectory-planning paths using MATLAB.
