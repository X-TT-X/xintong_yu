1. Sign in to GitHub and create a public repository named portfolio (main branch).
2. Upload index.html, style.css, app.js, assets/ and .nojekyll, preserving folders.

4. Wait for the deployment; use the exact URL shown by Pages. It is normally https://YOUR-USERNAME.github.io/portfolio/.
Alternatively include .github/workflows/pages.yml and select GitHub Actions as the Pages source.
