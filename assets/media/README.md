# Original project media

Only add personal project recordings or employer-approved public media. No third-party reference GIFs are used.

1. Place .mp4, .webm, .gif, .jpg or .png files here.
2. Edit ../../media-catalog.js. Set the matching src to assets/media/your-file.mp4.
3. Use type: video for MP4/WebM, gif for GIF and image for stills; add caption and optional poster.
4. Add a real repository URL under repository when public. It will appear on the corresponding detail page.
5. Refresh the page. This works from file:// and GitHub Pages; no build required.
